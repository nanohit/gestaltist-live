# gestaltist.live

Лендинг онлайн-конференции «Актуальные вопросы гештальт-терапии» (SvelteKit 5) на Vercel.

## Как это устроено

- **Страница** рендерится на сервере и отдаётся посетителям со статического
  edge-кэша Vercel (ISR, `expiration: 60`). Для посетителя это обычная статика:
  функция просыпается не чаще раза в минуту.
- **Контент** живёт в Turso (libSQL). Правки из админки летят в `PUT /api/content`
  и появляются на сайте в течение минуты.
- **Снапшот** `src/lib/content.snapshot.json` вшит в сборку и используется,
  если база недоступна, — сайт не падает и не показывает заглушки.
- **Картинки** спикеров и логотип проходят через Vercel Image Optimization
  (`/_vercel/image`): avif/webp нужного размера с edge-кэша.
- **Шрифт** Geometria лежит в `static/fonts` — без сторонних CDN.

## Разработка

```bash
npm install
cp .env.example .env   # вписать доступы к Turso
npm run dev
```

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `TURSO_DB_URL` | адрес базы с контентом |
| `TURSO_DB_AUTH_TOKEN` | токен доступа к базе |
| `ADMIN_LOGIN` | логин админки (по умолчанию `admin`) |
| `ADMIN_PASSWORD` | пароль админки (по умолчанию `123456789` — поменять!) |

## Админка

Вход — по прямой ссылке `/?admin` не предусмотрен: кнопка входа в футере.
Пароль проверяется на сервере (`POST /api/auth`), в бандл он не попадает.
Сохранение требует заголовок `x-admin-token`, поэтому чужой `PUT` не пройдёт.
